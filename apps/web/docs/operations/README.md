# Operations logs

Human-gated evidence and decision tracking for live-provider proofs and long-running verification work.

| File | Role |
|------|------|
| `EVIDENCE.md` | Append-only run evidence (Playwright and manual proofs) |
| `DECISIONS_NEEDED.md` | Open decisions and resolved gates |
| `COVERAGE.md` | Capability coverage matrix |
| `STATUS.md` | Session / ticket status narrative |

Paths are referenced from `e2e/support/operations-docs.ts` so Playwright specs stay aligned with this folder.
